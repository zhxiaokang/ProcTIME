# ProcTIME
Study of Tumor Immune Micro-environment of prostate cancer. 

Use the deconvoluted cell composition to find subgroups of TCGA cohort and train a deep learning model to predict the risk score of the biochemical recurrence on TCGA dataset and test the trained model on MSKCC dataset.

More details can be found [here](https://docs.google.com/document/d/15lr5KaEfUqDadutHcURql76eIV9gH8jTi1Uv2u85IyA/edit?usp=sharing).
